# Monitoramento de CO₂ — Frontend

Repositório do dashboard;

## Objetivo

Criar uma interface para visualizar os dados coletados pelos sensores e acompanhar as condições do ambiente.

## Funcionalidades previstas

- Exibição dos níveis de CO₂, temperatura e umidade.
- Atualização dos dados em tempo real.
- Visualização do histórico de medições.
- Alertas visuais conforme as condições monitoradas.
